# Day 3 (일) — 반품, 감사로그, 대시보드, 마무리

## 1. 오늘의 목표

예외 흐름(반품)과 시스템 기능(감사로그, 대시보드 SSE)을 완성하고 시연 가능한 상태로 마무리한다.

## 2. 관련 범위

- 요구사항: `REQ-021`~`REQ-025`, `NFR-003`, `NFR-004`
- 작업: `TASK-010`~`TASK-014`
- 범위 밖: 스케줄, 지도, 3D, 신규 기능 추가

## 3. 세부 개발 내용

### 3.1 반품 (TASK-010)
- 배송 실패 시 반품 자동 생성, 회수요청 → 회수중 → 회수완료 → 반품입고 → 처리완료
- 반품입고: 파손이 아니면 지정 위치 재고 복구, 파손은 복구 없음

### 3.2 감사로그·Kafka (TASK-011)
- `AuditConsumer`: 상태 변경 이벤트를 `audit_log`에 기록, `processed_event`로 멱등
- 감사로그 검색 API(기간·사용자·대상·작업), 주문 상세 이벤트 이력 연동
- 역직렬화 오류와 업무 오류 구분, 무한 재시도 방지

### 3.3 대시보드·Redis·SSE (TASK-012)
- 요약(카드 7개+진행 현황), 차량 현황, 최근 이벤트 API
- Redis Cache-Aside, 이벤트 소비 시 무효화, 장애 시 DB 폴백
- `DashboardConsumer`가 SSE `status-changed` 브로드캐스트

### 3.4 프런트 (TASK-013)
- 반품 목록/상세, 감사로그 목록·검색, 대시보드(SSE 수신 시 요약 재조회·이벤트 추가)

### 3.5 마무리 (TASK-014)
- `ORD-001` E2E, 실패→반품 시나리오 테스트
- README(실행 방법, 아키텍처, 한계: Kafka 발행 실패 시 재처리), 데모 스크립트
- 여유 시 k6 대시보드 캐시 OFF/ON 비교

## 4. 테스트와 검증

- 반품 상태 전이, 재고 복구/미복구, 이벤트 중복 소비 멱등
- 캐시 무효화, Redis 장애 폴백, SSE 브로드캐스트
- 전체 테스트와 빌드, Docker Compose 기동
